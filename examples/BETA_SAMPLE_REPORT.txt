INTERPRETATION / 解釈
Character offsets are zero-based UTF-16 [start,end); supplementary pairs remain one observation. These are not grapheme boundaries.
fontIdentity VERIFIED requires direct CharacterRange.fontObject plus a readable fontID or PostScript name. Base TextDocument font is never substituted for an unreadable character font.
VERIFIED_PRESENT/VERIFIED_ABSENT mean hasGlyphsFor returned a boolean for that applied font and code point. They do not prove rendered fallback or shaping correctness.
NOT_CHECKED means no reliable query was made; FAILED means the glyph API getter/query failed or returned an invalid value. Neither is PASS.
UNKNOWN records unavailable or failed reads. Complete mixed-font classification needs unique font IDs for every character; intentional mixing is REVIEW_NEEDED.
Animated/expression Source Text, whole-project scanning, font installation/replacement, rendered-fallback identification, and full shaping validation are outside beta scope.
Project revision equality is one observation, not proof of all project/UI state invariance; UNKNOWN never means unchanged/PASS.
